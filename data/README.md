# Data

This repository uses terrestrial water storage (TWS) observations from the
GRACE and GRACE Follow-On satellite missions.

## Standardised Terrestrial Water Storage Index (STWSI)

The country-level analysis requires the following global monthly STWSI dataset:

`CSR_GRACE_Global_Standardised_TWSI_03_25.tif`

The dataset covers January 2003 to December 2025.

The Standardised Terrestrial Water Storage Index (STWSI) is derived from
monthly GRACE terrestrial water storage observations. In the analysis for
The 2026 Report of the Lancet Countdown on Health and Climate Change,
extremely dry terrestrial water storage conditions are defined as:

STWSI < -1.5

Changes in the frequency of extremely dry conditions are calculated by
comparing the baseline period (2006–2015) with the recent period (2016–2025).

## Country boundaries

The analysis uses the ESRI World Countries Generalized dataset for
country-level spatial aggregation.
